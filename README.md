# 🔥 萤火网格1.0 (YingHuo Grid v1.0)

> 手工锚仓 + 马丁加仓 + ATR 间距的加密货币永续合约网格交易系统，**全自动闭环执行**。

针对手工锚仓的永续合约网格：你手动开一个「锚仓」定方向，系统在锚仓基础上挂一层 ATR 动态网格，用马丁递增摊薄成本、单格止盈保存利润、两档总止盈止损控制风险——全自动下单，无需人工盯盘。

## ✨ 特性

- **全自动闭环**：每 60s 自动扫描并接管交易所持仓，自动马丁加仓 / 单格止盈 / 总止盈止损，全部自动下单
- **趋势过滤器**：除 BTC/ETH 外，单边行情自动暂停加仓（回测平均降回撤 **36%**）
- **仓位流水账**：每次加/减/接管/清仓自动落盘，LIFO 精确算盈亏，可复盘可审计
- **多空镜像**：做多与做空同一套规则、方向相反
- **账户级熔断**：总浮亏 ≥20% 自动暂停所有新加仓
- **防踏空**：单边上涨网格不空转，自动跟随上移基准

## 📐 核心规则

| 环节 | 规则 |
|---|---|
| 网格间距 | 基于 ATR 动态计算，跟随波动 |
| 马丁加仓 | 递增加仓摊薄成本，封顶控敞口 |
| 单格止盈 | 反弹减仓锁利（LIFO） |
| 总止盈 | 分批止盈，利润落袋 |
| 总止损 | 分批止损兜底，防深套 |
| 趋势过滤 | 单边行情自动暂停加仓 |
| 账户熔断 | 总浮亏超标全局暂停新加仓 |

## 📊 回测数据（90 天 × 8 币，1h K线）

趋势过滤器「有 vs 无」对比：

| 币 | 回撤 无→有 | 收益 无→有 |
|---|---|---|
| UNI | **82.9% → 39.8%** | +26.9 → +22.2U |
| XRP | 25.4% → 9.4% | +37.6 → +27.5U |
| LTC | 11.0% → 9.7% | +37.5 → +25.2U |
| BTC | 6.6% → 5.6% | +37.4 → +28.4U |
| ETH | 8.0% → 6.4% | +39.7 → +29.2U |

**汇总**：平均回撤 21.9U → 14.0U（**-36%**），总收益 -19%（用收益换回撤，性价比因币而异）。

## 🚀 快速开始

```bash
# 依赖
pip install ccxt

# 配置参数（复制示例配置，填入你的参数；付费订阅版提供回测调优参数）
cp strategy_params.example.json strategy_params.json

# 查看状态（自动从交易所同步持仓）
python3 scripts/manual_grid_atr.py status

# 登记锚仓
python3 scripts/manual_grid_atr.py add BTC/USDT long 0.003 84277.5 fixed

# 常驻自动扫描（每 60s）
python3 scripts/manual_grid_atr.py watch 60
```

常用命令：`status` / `add` / `remove` / `unignore` / `atrmult` / `trendfilter` / `sync` / `journal` / `run` / `watch`
