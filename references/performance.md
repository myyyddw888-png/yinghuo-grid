# 萤火网格1.0 回测与绩效数据

## 一、趋势过滤器回测（90 天，1h K线，2026-07-09 → 2026-10-07）

**口径**：锚仓 100U 固定；马丁 20U 基准（前3格×1.5、第4格起×1.7、5格封顶）；间距 1×ATR；趋势过滤器 = 收盘价跌破 EMA113(4h) 时暂停加仓。

对比「A 无过滤器（一直加仓）」vs「B 有过滤器（趋势停加仓）」：

| 币 | 回撤 A→B | 收益 A→B | 加仓 A→B |
|---|---|---|---|
| BTC | 6.6% → 5.6% | +37.4 → +28.4U | 32 → 13 |
| ETH | 8.0% → 6.4% | +39.7 → +29.2U | 37 → 16 |
| XRP | 25.4% → 9.4% | +37.6 → +27.5U | 17 → 2 |
| ZEN | 13.7% → 13.7% | +28.0 → +28.0U | 0 → 0 |
| DOT | 18.1% → 18.1% | +29.5 → +25.5U | 14 → 0 |
| LTC | 11.0% → 9.7% | +37.5 → +25.2U | 32 → 1 |

| ENA | 9.4% → 9.4% | +27.1 → +27.1U | 0 → 0 |

**汇总**：平均回撤 **21.90U → 14.00U（降 36%）**；总收益 **+263.5U → +213.2U（降 19%）**。

### 关键结论

1. **趋势过滤器本质是「用收益换回撤」**，性价比因币而异。
2. **高波动/易单边暴跌币最受益**：UNI 回撤 82.9%→39.8%（几乎腰斩，少赚仅 4.7U）、XRP 25.4%→9.4%。这类币马丁加仓在单边下跌时会一路套死，停加仓是保命。
3. **低波动大市值币不划算**：BTC/ETH 回撤本就 6-8%，过滤后只降 1-2U 却少赚 9-10U，底部加仓的反弹利润被白白牺牲。
4. **锚仓本身是回撤的主要来源之一**（如 DOT/ENA 加仓 0 次回撤已 9-18%）：过滤器只影响「加仓带来的回撤」，管不住锚仓开仓时机。

**落地决策**：除 BTC/ETH 外全挂过滤器，高波动币重点保护。
